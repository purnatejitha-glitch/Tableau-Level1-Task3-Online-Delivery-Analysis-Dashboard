Tableau Level 1 – Task 3: Online Delivery Analysis Dashboard

Project Overview

This project analyzes restaurant data using Tableau Public to understand online delivery availability and compare restaurant ratings.

Objectives

- Determine the percentage of restaurants that offer online delivery.
- Compare average ratings of restaurants with and without online delivery.
- Create visualizations to analyze online delivery services.
- Build an interactive dashboard using Tableau Public.

Tools Used

- Tableau Public
- Restaurant Dataset

Key Insights

- Analyzed the percentage of restaurants offering online delivery.

- Identified differences in restaurant ratings based on delivery availability.
- Created visualizations to understand online delivery trends.
